# 🛡️ ChurnShield — AI-Powered Customer Retention Analytics

A machine learning project that predicts customer churn for a telecom business, using the real-world **IBM Telco Customer Churn dataset** (7,043 customers). Includes a full ML pipeline — EDA, class imbalance handling (SMOTE), model comparison, hyperparameter tuning, business impact analysis, customer segmentation, and a deployable Streamlit app for live predictions.

## 🎯 Business Problem

Telecom companies lose ~26% of customers to churn. This project builds a model to flag at-risk customers early, so retention teams can act before they leave — and estimates the revenue impact of doing so.

## 📂 Project Structure

```
├── Customer_Churn_Prediction.ipynb   # Full analysis notebook (EDA → Models → Business Impact)
├── app.py                            # Streamlit app for live churn prediction
├── churnshield_model_pipeline.pkl          # Saved trained model (generated by the notebook)
├── requirements.txt                  # Python dependencies
└── README.md                         # This file
```

## 🧠 Techniques Used

| Category           | Details                                                                                                       |
| ------------------ | ------------------------------------------------------------------------------------------------------------- |
| Data Source        | [IBM Telco Customer Churn](https://github.com/IBM/telco-customer-churn-on-icp4d) (real, public dataset)       |
| Preprocessing      | `ColumnTransformer` (OneHotEncoder + StandardScaler) inside `sklearn.Pipeline`                                |
| Imbalance Handling | SMOTE (via `imbalanced-learn`), applied correctly only within training folds                                  |
| Regression         | Linear Regression (predicting Total Charges / revenue)                                                        |
| Classification     | Logistic Regression, KNN, Decision Tree, Random Forest — compared on Accuracy, Precision, Recall, F1, ROC-AUC |
| Model Tuning       | GridSearchCV over the full pipeline                                                                           |
| Clustering         | K-Means with Elbow Method (customer segmentation)                                                             |
| Deployment         | Streamlit app loading the saved pipeline for real-time predictions                                            |

## 📊 Key Results

- Best model: **Random Forest** (tuned) — ROC-AUC ≈ 0.84, Accuracy ≈ 77%
- Top churn drivers: **Contract type**, **tenure**, and **Internet Service type**
- Business finding: Month-to-Month customers churn at **42.7%** vs **2.8%** for Two-Year contracts

## 🚀 How to Run

**Notebook (Google Colab or Jupyter):**

1. Open `Customer_Churn_Prediction.ipynb`
2. Run all cells — the dataset is loaded directly from a public URL, no manual download needed

**Streamlit App (locally):**

```bash
pip install -r requirements.txt
streamlit run app.py
```

> Note: run the notebook first so `churnshield_model_pipeline.pkl` exists, or use the one already included in this repo.
